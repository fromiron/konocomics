# 작품 팩터 주석 가이드

> 이 문서는 `factor-dictionary.md`의 정의를 실제 작품에 일관되게 적용하기 위한 대표 사례와 경계 사례를 축적한다. 팩터 정의나 추천 산식을 새로 정하지 않는다.

## 1. 적용 범위

- 초반 1~3권 또는 첫 주요 에피소드에서 사용자가 실제로 겪는 진입 경험만 평가한다.
- 후반 반전, 결말, 장기 연재 중 변화는 초반 근거와 섞지 않는다.
- 작품을 보지 못했거나 근거가 부족한 항목은 낮은 값이 아니라 `unknown`으로 둔다.
- `notApplicable`은 팩터 사전이 허용한 조건부 축에만 사용한다.
- 공식 근거는 원권리 출판사뿐 아니라 정식 라이선스를 받은 해외 출판사와 출판사 승인을 확인할 수 있는 플랫폼도 허용한다. 라이선스·승인 관계는 권리 표기나 출판사 공식 링크로 확인해 함께 기록한다.

## 2. 주석 순서

1. 작품·대표 권·판형이 올바르게 그룹핑됐는지 확인한다.
2. 공식 소개와 초반 권의 관찰 가능한 근거를 기록한다.
3. Genre와 Theme 중심성을 판정한다.
4. 각 Axis를 먼저 0·2·4 기준에 대조하고, 명확히 사이에 있을 때만 1·3을 사용한다.
5. confidence와 evidence를 기록한다.
6. eligibility와 대표 volume을 확인한다.
7. 다른 주석자가 기존 값을 보지 않은 상태에서 재태깅할 표본 여부를 기록한다.

## 3. 근거 기록 규칙

| 항목 | 기록 내용                                       |
| ---- | ----------------------------------------------- |
| 출처 | 라쿠텐·출판사·수동 확인 등 실제 출처 종류와 URL |
| 범위 | 확인한 권 또는 첫 주요 에피소드                 |
| 관찰 | 팩터 판정을 지지하는 사건 구조·빈도·반복 패턴   |
| 한계 | 확인하지 못한 범위와 `unknown`으로 남긴 이유    |
| 검수 | 검수자와 검수 시각, 블라인드 재태깅 여부        |

줄거리 요약만으로 작화의 `motionImpact`를 확정하지 않는다. 표지 한 장만으로 전체 작화 축을 확정하지 않는다. Art는 승격의 필수 coverage가 아니며 이미지와 커뮤니티 중 어느 근거 경로도 없으면 `unknown`으로 둔다.

### Art 4축 선택 근거 경로

- **이미지 경로:** 평가 범위와 판본이 일치하는 판독 가능한 내부 페이지 또는 동등한 정지 프레임을 최소 6개, 서로 다른 장면·맥락을 최소 2개 확인한다. 각 known 정적 축은 최소 2개의 정확한 참조를 남긴다. known `motionImpact`는 하나의 연속 동작 시퀀스와 시작·끝 참조가 필요하다. 판본 관계, 표본 해시와 한계를 기록한다.
- **커뮤니티 경로:** 공식 자료로 작품·초반 1~3권 또는 첫 주요 에피소드 범위를 고정한 뒤, 서로 복제되지 않은 독립 리뷰 2개 이상이 같은 구체적 시각 관찰을 반복해야 한다. URL, 작성 주체, 게시일·조회일, 독립성, 평가 범위, 반복 관찰과 0/2/4 기준의 연결을 기록한다. 일본 커뮤니티와 한국어 제목·표기 변형으로 찾은 한국 커뮤니티를 별도 층으로 남긴다.
- 두 경로는 동급이며 함께 요구하지 않는다. 한 작품 안에서 같은 Art 판정 묶음은 선택한 경로를 명시하고, 근거를 혼합해 출처 책임을 흐리지 않는다.
- 단일 리뷰, 복제·신디케이션, 범위 불명, 별점·순위, “예쁘다”·“박력 있다” 같은 비구체 호불호는 제외한다. `motionImpact`는 커뮤니티 경로에서도 동작 연출·속도·타격 표현의 반복 관찰이 명시돼야 하며 단순한 액션 장르 언급은 부족하다.
- 어느 경로도 최소선을 충족하지 못한 축은 `unknown`이다. 근거를 구할 수 없다는 이유로 `notApplicable`을 쓰지 않으며, `motionImpact=notApplicable`은 확인한 평가 범위에 동적 장면 자체가 없을 때만 쓴다.

## 6. 블라인드 재태깅

- 동결된 G1 cohort ID와 고정 알고리즘으로 15~20%를 결정론적으로 선정하되 기존 점수를 숨긴다.
- 원 주석과 2단계 이상 차이가 난 축을 모두 기록한다.
- 차이를 단순 평균하지 않고 정의·근거·작품 범위를 다시 확인한다.
- 합의로 정의가 바뀌면 팩터 사전 버전과 기존 데이터 재검토 범위를 함께 갱신한다.

## 7. 완료 체크리스트

- [ ] 대표 volume과 ISBN이 존재한다.
- [ ] 추천 대상의 필수 coverage가 충족된다.
- [ ] 모든 known 값에 판정 근거가 있다.
- [ ] known Art 값은 선택한 이미지 또는 커뮤니티 근거 경로의 최소선을 충족한다. Art가 전부 `unknown`이어도 승격을 막지 않는다.
- [ ] `unknown`과 실제 0이 구분된다.
- [ ] Theme centrality 1·2의 차이가 근거에 드러난다.
- [ ] eligibility 값끼리 충돌하지 않는다.
- [ ] 검수 상태와 confidence가 기록됐다.
