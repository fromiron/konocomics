# 홈 모션 히어로 — 장르별 「コマ」 키비주얼

> 상태: 동작하는 프로토타입 구현(2026-10-04). 사용자 결정으로 기존 홈 구현은 폐기 대상이며, 모션 그래픽 사양은 이 문서가 정한다. 히어로 아래 섹션(띠지·사용법·선반)은 이번 범위가 아니다.

## 0. 결론

- 히어로는 어두운 캔버스 위의 **만화 원고 한 장**이다. 원고 옆에 세로쓰기 타이틀을 세운 매거진 표지 구도이며, 좁은 화면에서는 원고 아래 가로 타이틀로 바꾼다.
- 장면은 장르별로 연출 문법이 다르다(색만 바꾸지 않는다).
  - **学園バトル(스타카토):** 반응 인셋이 먼저 놀라고, 집중선이 꽂히고, 소년이 몸을 뒤로 당겼다가 뻗는다. 펼친 손 하나만 컷의 테두리를 뚫고 독자 쪽으로 나온다.
  - **ラブコメ(레가토):** 그녀가 고개를 숙이고(첫 인셋), 올려다본다(둘째 인셋). 메인 컷은 두 사람이 함께 쥔 책에서 시작해 눈이 마주치는 얼굴까지 카메라가 천천히 올라간다. 각 인셋에서 나온 실이 그녀에게 닿고, 그 순간 꽃잎이 두 얼굴 사이를 지나간다.
- 새로고침할 때마다 장면을 무작위로 고르되, 같은 탭의 직전 장면은 반복하지 않는다(사용자 요청). 인트로는 매 로드마다 재생한다.
- 장르를 고르는 버튼은 두지 않는다(사용자 결정). 화면의 조작은 일시정지 하나뿐이다.
- 새 의존성은 없다. 브라우저 Web Animations(WAAPI)와 CSS를 쓰고, 이미지 변환은 로컬 CLI로 오프라인에서 한다.

## 1. 입력

| 장르 | 전달 폴더(원본, 저장소 밖) | 레이어 |
|---|---|---|
| 러브코미디 | `tmp/러브코미디/` | 맞닿은 손을 고정한 2인 전신 1장, 확장 인셋 초상 2장, 캠퍼스 배경(overscan), 패널 종이·잉크·인셋 매트·감정 곡선(2304×1792, 원본 원점 384,384), 꽃잎(전체·그룹 3·개별 23) |
| 학원 배틀 | `tmp/학원물/` | 소년 전신 A, 반응 초상 B·C, 배경·집중선 plate(overscan), 흰 여백 다각형, 원본 좌표 패널 잉크 |

- 모든 레이어를 각 `assetmap.json`/`asset-map.json`의 등록 변환(`source = native × scale + translate`)으로 다시 쌓아 승인 원본(1536×1024)과 대조했다.
- 전달 문서대로 생성 재구성본이라 픽셀 단위 일치는 아니며, 2인 레이어는 책·손 접점을 지키기 위해 한 장이다.
- 배틀 인셋 경계는 잉크 레이어에서 읽어 `(877,0)…(722,163)` 다각형으로, 러브코미디의 실 두 가닥은 아크 레이어 픽셀을 추적해 경로로 만들었다(`scenes/*.ts`에 출처 주석).
- 투명 경계는 밝은/어두운 바탕에서 확인했다. AVIF(q66, 4:4:4)는 확대 비교에서 선화·해칭 손실이 거의 없다.

## 2. 연출 방향 결정

| | A. 視線リレー | **B. コマを越えて(채택)** | C. インクから色へ |
|---|---|---|---|
| 시선 | 인물 시선을 따라 패닝 | 일본 만화 읽는 순서대로 컷이 열림 | 색이 번지는 앞선 |
| 카메라 | 큰 확대 후 풀백 | 거의 고정, 한 요소만 평면을 넘음 | 느린 달리 |
| 탈락 이유 | 레이어 해상도 여유 부족(2인 레이어가 이미 원본 대비 1.59배 확대) | — | 필터 흑백은 원고처럼 보이지 않음 |

B를 장르 문법에 맞게 나눴다.
- 배틀은 「はみ出し」(컷 밖으로 손)가 강조점이다.
- 러브코미디는 컷 안 카메라 틸트와 「赤い糸」(인셋에서 이어진 실)가 강조점이다.
- 두 장면 모두 컷 테두리는 고정하고, 카메라는 컷 안에서만 움직인다.

## 3. 장면 사양

시간은 인트로 시작(레이어 디코드 완료) 기준 ms이고, 거리는 원본 px이다. 정확한 값은 `src/features/home-hero/scenes/*.ts`가 단일 출처다.

### 3.1 学園バトル — 컷 `[0,0,1536,830]`(원고 1536×1024의 위쪽)

| t | 비트 | 움직임 |
|---|---|---|
| 0 | 첫 화면 | 흰 원고에 인셋 잉크 선만 있다. 카피와 CTA는 이미 읽고 누를 수 있다 |
| 250–860 | 반응 인셋 | 인셋 배경이 나오고, B(300ms)와 C(400ms)가 y +20/+28에서 살짝 넘쳤다가 제자리로 온다(놀람) |
| 700–1700 | 메인 컷 | 배경 scale 1.08→1(카메라 돌진), 흰 여백, 집중선 1.35→1로 수렴 |
| 820–1180 | 예비 동작 | 소년이 뒤쪽 어깨 기준 scale 0.8→0.775로 더 물러난다 |
| 1180–1400 | **강조** | 소년이 1.045까지 뻗고, 손이 컷 아래 테두리와 종이 여백을 넘는다(약 1.33초에 테두리 통과) |
| 1390–1640 | 충격 | 원고가 240ms 흔들리고, 흰 섬광이 opacity 0.28로 한 번 난다. 집중선이 1.06으로 튄다 |
| 1400–2050 | 정착 | 0.992를 거쳐 1.0으로, 승인 구도와 같다 |
| 2200~ | 반복 | 배경이 손 쪽으로 12초 주기 1.5% 기운다. 집중선은 3초 주기 2.8%로 긴장 맥동한다. 인셋 하늘은 8초 주기로 8px 흐른다. 인물은 멈춰 있다 |

손만 컷 밖에 나오도록 소년 레이어를 컷 밖 평면에 한 번 더 그린다. 엄지 윤곽을 따라 딴 손 마스크를 쓰고, 테두리보다 18px 위에서 시작하는 클립을 씌워 손이 먹선 테두리를 덮는다(테두리에 잘려 보이지 않음). 손은 컷 아래 같은 원고의 흰 종이 위에 놓인다. 충격 섬광은 원고 전체를 덮어 손과 컷이 같은 밝기로 바뀐다.

### 3.3 공통 원칙

- 인물을 늘리거나 회전하지 않는다. 인물을 띄워 반복 이동시키지 않는다. 회전은 꽃잎에만 쓴다.
- 모든 인트로 트랙은 승인 정지 구도에서 끝난다. 반복 트랙은 정지 구도에서 속도 0으로 시작하고 끝나며, 꽃잎·빛 띠는 화면 밖에서만 위치를 되돌린다.
- 같은 노드의 같은 속성을 두 트랙이 갖지 않는다. 인트로·반복은 서로 다른 요소(`node`, `node:loop`)의 transform을 소유한다.

## 4. 웹 동작

| 상황 | 동작 |
|---|---|
| 일반 진입·새로고침 | 직전과 다른 장면을 무작위로 고르고(탭 `sessionStorage.homeHeroScene`), 디코드 후 인트로를 재생한 뒤 반복으로 넘어간다 |
| 같은 로드 안에서 홈으로 돌아옴 | 같은 장면, 인트로 재생 |
| `?landing=1` | 저장소를 읽거나 쓰지 않는다. SSR과 맞추기 위해 배틀로 고정한다 |
| 디코드가 1.5초 안에 끝나지 않음 | 인트로를 생략하고 정착 화면부터 반복한다 |
| `prefers-reduced-motion: reduce` 또는 WAAPI 없음 | 애니메이션을 만들지 않는다. CSS 기본값이 곧 승인 정지 구도다. 일시정지 버튼도 없다. 실행 중 전환 시 즉시 정지 구도로 바뀐다 |
| 일시정지 | 현재 프레임에서 멈춘다. 탭 안 새로고침에도 유지되며(`homeHeroMotion`), 이때는 정착 화면에서 멈춘 채 시작한다. 스크롤·탭 전환으로 자동 해제되지 않는다 |
| 화면 밖·비활성 탭 | 멈췄다가 돌아오면 이어서 재생한다. 끝난 인트로는 다시 재생하지 않는다 |
| 카피·CTA | 아트 transform 트리 밖에 있어 첫 프레임부터 조작할 수 있다. 스크롤·입력을 가로채지 않는다 |

- **원고 크기:** 모든 장면이 1536×1024 원고 한 장을 공유하므로 히어로의 높이·폭은 장면과 무관하게 같다. 컷(먹선 프레임)만 장면별 크기를 갖는다.
- **타이틀 컷:** 원고 안에 그림 컷과 같은 먹선의 타이틀 컷을 둔다. 넓은 화면에서는 오른쪽 세로쓰기이고 높이는 그림 컷에 맞춘다. 글자 크기는 화면 높이에서 계산한다. 좁은 화면에서는 그림 컷 아래 가로쓰기다.
- 아트 전체는 `aria-hidden` 장식이다. H1은 타이틀 컷 안의 태그라인 하나이며, 세로쓰기에서도 문구 단위로만 줄을 나눈다.
- 일시정지 버튼은 44px 조작 영역에 상태별 접근 이름(「アニメーションを一時停止/再生」)을 붙여 타이틀 컷 모서리에 둔다.
- 홈에는 사이트 헤더 메뉴가 없으므로(§8) 브랜드 행을 모든 화면에서 원고 위에 둔다.

## 5. 구현 구조

```text
scripts/home-hero/prepare-assets.ts   전달 PNG → 필요한 영역만 crop → AVIF/WebP(원본·절반) + 배치 manifest
src/features/home-hero/
  scene-assets.json / scene-assets.ts  생성 manifest(zod 파싱)와 해시 URL·srcset
  scene-types.ts                      원본 좌표계·레이어·트랙 타입
  scenes/battle.ts, scenes/romance.ts 장면별 레이어·인트로·반복(조정값은 여기서만)
  hero-stage.tsx                      원고 DOM: 종이 여백·컷 창·컷 밖 평면·채널 래퍼·실 마스크
  scene-playback.ts                   트랙 → WAAPI, 공유 시계(seek/play/pause/cancel), 디코드 대기
  home-hero-scene.tsx                 장면 선택·일시정지·가시성·모션 감소, 스프레드 레이아웃
src/features/landing/home-hero.tsx    카피·CTA·세로쓰기 타이틀을 스프레드에 배치
tests/unit/home-hero/scene-definitions.test.ts
```

- 레이어는 원본 좌표계(1536×1024)를 %로 배치하고, 이동 거리는 그 좌표계의 `cqw`로 쓴다. 창 크기가 바뀌어도 비율이 유지된다.
- 데스크톱 원고 너비는 `(100svh − 16rem) × 1.5`에 타이틀 컷 폭을 더한 값으로 제한해 카피와 CTA가 첫 화면에 남게 한다.
- 개발 빌드에서만 `?heroScene=battle|romance&heroSeek=<ms>`로 한 프레임을 고정하고, `window.__homeHero.seek/play/pause`로 같은 시점을 재현한다. 프로덕션 클라이언트 번들에는 이 코드가 없다.
- 변환 생성물은 2.9MB(두 장면, 두 포맷, 두 크기)이고, 한 로드는 한 장면·한 포맷만 받는다(실측 86–132KB).

## 7. 남은 한계와 다음 결정

- **성능:** 이 프로필에서 LCP는 `04` §8의 3.5s 목표를 넘는다. 주된 원인은 히어로 이전의 JS·하이드레이션·프로필 확인 경로이므로, 홈 전면 개편에서 그 경로를 줄이는 것이 먼저다. 실기기 측정은 하지 않았다.
- **화질:** 러브코미디 2인 레이어는 원본 대비 1.59배, 배틀 소년은 1.25배 확대된 등록이라 고밀도 화면에서 선이 약간 부드럽다. 더 큰 원본 레이어가 오면 `prepare-assets.ts`만 다시 돌리면 된다.
- **추가 애셋(반복 장면의 생명감):** 눈 감은 얼굴 패치, 긴 머리 끝 분리 레이어 + pivot이 있으면 깜빡임·머리 흔들림을 넣을 수 있다. 지금 반복은 카메라·빛·꽃잎·집중선만 움직인다.
- **E2E·문서:** 기존 `03`/`04`의 랜딩 서술(「例」 카드가 히어로 오른쪽 등)은 이 구현과 다르다. 사용자 지시로 계약 대조를 생략했으므로 홈 개편 확정 때 함께 갱신한다.

## 8. 라이트 테마와 홈 개편(2026-10-05)

사용자 결정으로 모션 히어로에 맞춰 프로젝트 전체를 라이트 테마로 바꿨다. 홈은 이번에 다듬었고, 다른 화면은 토큰 전환 결과만 확인했다.

- **토큰:** `:root`를 만화 원고 종이(`--canvas` 따뜻한 오프화이트)와 먹(`--text-strong`)으로 바꿨다. 앰버 채움(`--accent`)은 유지하고, 글자에 쓰는 앰버는 대비를 위해 `--accent-ink`(`text-accent-ink`)로 분리했다. 포커스 링도 `--accent-ink`다. 그림자·대화상자 스크림·포인터 광택·스위치 손잡이처럼 다크를 전제로 한 값을 라이트용으로 바꿨다.
- **홈 구조:** 홈에서는 상단 메뉴를 숨긴다. 프로필이 있으면 추천 화면으로 이동하므로 홈은 처음 온 사람만 본다. 순서는 브랜드 행 → 모션 원고와 세로쓰기 타이틀 → 카피·CTA → 세 컷 예시 → Top 10 → 발견 선반 → 마무리 컷 → 푸터다.
- **세 컷 예시:** 하나의 샘플 프로필로 「選ぶ」(선택한 5작품 표지) → 「好みが見える」(Manga DNA 상위 4축) → 「理由つきでおすすめ」(엔진 추천과 `contributions[]` 이유)를 먹선 컷으로 잇는다. 이전의 띠지와 따로 떠 있던 「例」 카드는 여기로 흡수했다.
- **마무리 컷:** 먹선 테두리 오른쪽에서 스크린톤이 번지는 패널 안에 같은 CTA를 둔다.
- **확인:** 1440×900·390×844·320×568에서 문서 가로 넘침 0. 온보딩·DNA·추천·작품 상세·라이브러리·설정을 라이트 테마로 캡처해 읽기 어려운 곳을 고쳤다(스위치 손잡이 등). 그 화면들의 세부 다듬기는 다음 작업이다.
- **남은 문서:** `AGENTS.md`의 dark-only 규칙과 `03`/`04`의 다크·랜딩 서술은 아직 갱신하지 않았다.
