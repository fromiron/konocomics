konocomics foundations

종이와 잉크 방향을 유지하면서 Slice 5 온보딩과 Slice 6 취향 화면의 반복값을 primitive와 semantic 역할로 정리했다. 값은 기존 사양·CSS·온보딩 렌더에서만 도출했으며 새로운 시각 방향을 추가하지 않았다.

근거: 04 사양, globals.css, 1440px/390px onboarding·taste product renders 작성: 2026-08-14 상태: Grok/Gemini 독립 리뷰 통합, 예외 2건은 계속 review-required
검토 경계. 구조화 검사 결과는 review-required다. 미해결 overage나 radius mismatch는 없지만, 999px pill radius와 A–F 6개 기능성 모션 분류는 기본 예산을 넘는 문서화된 예외다. 두 모델 리뷰의 필수 수정은 통합했지만 모델 리뷰를 자동 pass로 바꾸지 않는다. `/taste`의 실제 1440px/390px 제품 흐름은 통합 브라우저 검증에서 확인했다.

Motion roles

기본 2종 예산보다 많지만 기능적 의미가 서로 달라 A–F 여섯 분류를 유지한다. duration/easing 토큰은 분류를 합치지 않고 값 드리프트만 막는다.

Functional motion exception
ClassMeaningDuration token/rangeReduced motion
Aone-time signature reveal400–1800ms; --motion-ease-signaturefinal state immediately
Bpage context entry--motion-duration-page 160msno motion
Clayout/data state transition200–240ms spring; domMax only at layout ownersimmediate layout
Ddirect manipulation feedback--motion-duration-press 80ms / feedback 120msopacity only
Enumeric value transition--motion-duration-value 240msimmediate value
Fattention/error boundary120ms ×2static full warn border replaces shake
예외가 보존하는 정보. A는 온보딩 보상, B는 화면 문맥, C는 항목의 이동 연속성, D는 입력 확인, E는 수치 변화, F는 오류·한도 인지를 전달한다. 이들을 두 종류로 합치면 trigger와 reduced-motion fallback의 계약이 사라진다. 대신 상시 loop, parallax, scroll hijacking, 분류 밖 모션은 계속 금지한다. Motion 기본 bundle은 domAnimation이고, 실제 layout continuity를 소유한 C 컴포넌트만 domMax를 쓴다.

Decisions and verification

초안, 예외, 거절, 미확인을 분리해 이 문서가 실제 검증보다 강한 주장을 하지 않게 한다.

  • Review-integrated draft: 위 token names와 values에는 Grok/Gemini 독립 리뷰의 근거 있는 수정이 반영됐고 실제 제품 flow 검증도 완료됐다. 남은 review-required 상태는 문서화된 radius·motion 예외의 사용자 판단만 뜻한다.
  • Retained exception: pill radius 1개와 기능성 motion A–F 6개. 접근성·상태·정보 손실 없이 줄일 근거가 없다.
  • Rejected: 외부 디자인 시스템 scale 복사, 새로운 breakpoint, 세 번째 폰트, 두 번째 accent, ambient animation, 소비자 없는 Tailwind spacing/radius 중복 매핑.
  • Verified: 온보딩과 `/taste`의 1440px/390px 실제 제품 흐름에서 grouping, target, mixed-script wrapping, fixed-control clearance, horizontal overflow를 검토했다. `/taste` DNA 제목의 computed font stack은 Space Grotesk와 Noto Sans JP를 함께 포함했다.
  • Remaining limit: proposal 자체는 system-ui specimen이므로 Noto Sans JP·Space Grotesk의 실제 글꼴 메트릭을 증명하지 않는다. 해당 증거는 제품 렌더와 computed style에만 결속한다.
  • Verification: proposal wide/narrow reflow, JSON checker, formatter, typecheck, lint, diff check와 실제 `/taste` 흐름의 computed token values·reduced-motion을 각각 확인한다.
이 파일은 네트워크 의존성이 없는 검토 아티팩트다. 제품 토큰의 구현 원본은 src/app/globals.css, 역할 계약은 docs/planning/04-visual-interaction-spec.md, 구조화 예산은 docs/planning/design-token-budget.json이다.
